# DMA Connect

Expo SDK 57 / React Native app for Dr. Mangesh Amale Foundation. Uses the original letterhead logo, white backgrounds, and purple accents.

## Run

Use Node.js 24.12 or later (Firebase SDK 13 requirement).

```sh
npm install
npm run web -- --port 8092
```

For a phone, run `npm start` and scan with Expo Go. `npm run ios` / `npm run android` launch an available simulator or emulator. Routes are managed with Expo Router under `src/app/`. Native directories are generated by Expo; use EAS for signed builds.

## App flow

- Animated logo splash, with reduced-motion support.
- Two-step president registration: name, email, mobile and password, then role and area. District, taluka, city, ward, village and cell roles show the relevant fields.
- Existing accounts can sign in, sign out, or request a password reset. Interrupted registration resumes profile setup after sign-in.
- Two main tabs: **Add member** and **Statistics**. iOS uses native system tabs with Liquid Glass on iOS 26 and later; earlier iOS versions use the system's standard tab appearance. Android and web retain the existing white and purple tab bar.
- Member form: name, optional email, Indian mobile, residence, DOB and taluka. Saves clear the form for the next member; failed saves preserve entered details. Taluka/ward/village accounts use their assigned taluka.
- Statistics: total members, registrations today, period totals, taluka distribution, animated activity bars and donut chart, 7/30-day and all-time filters, searchable member directory and full member details. Counts come from actual records, including empty states.

## Firebase

Live project: `dma-connect-foundation`. Named Enterprise Native database: `dma-connect`, in **Mumbai (`asia-south1`)**, with real-time updates enabled. Email/password Authentication is enabled.

`src/services/firebase-config.ts` contains the public Firebase client configuration. It is not an administrator credential. Native sign-in sessions use Firebase persistence backed by AsyncStorage; web sign-in uses Firebase browser persistence. Member records are stored in Firestore and sync after sign-in on another device. The old local member prototype is not automatically imported into a president account.

Data paths:

```text
presidents/{authUid}
presidents/{authUid}/members/{normalizedMobile}
```

Presidents read and create only their own records. Roles are descriptive and never grant access to another account. Rules validate document fields, ownership, contact formats, DOB bounds, server registration timestamps, and assigned taluka. Client updates/deletes are denied. A transaction and mobile-based document ID prevent duplicate members within the same president account. The creation-time index supports registration ordering.

Deploy changes to rules/indexes:

```sh
npx --yes firebase-tools@latest deploy --only firestore --project dma-connect-foundation
```

## Checks

```sh
npm run lint
npm run typecheck
npm test
npm run test:rules
npx expo-doctor
npx expo export --platform all
```

For isolated UI testing with Firebase’s local services:

```sh
npx --yes firebase-tools@latest emulators:start --only auth,firestore --project demo-dma-connect
EXPO_PUBLIC_USE_FIREBASE_EMULATORS=true npm run web -- --port 8092
```

The explicit development flag uses a separate Firebase app and demo project, never live records. Set `EXPO_PUBLIC_FIREBASE_EMULATOR_HOST` to the development machine’s LAN IP when testing from a phone. Restart without the flag to return to live Firebase. Production exports always use the live project.

Rules tests require Java 21+ and use the isolated `demo-dma-connect` emulator, never the live database. They cover authenticated/anonymous access, cross-account reads and writes, schema/role tampering, missing profiles, duplicate overwrites, date bounds and assigned areas.

Source: `src/context/` handles live sessions and members; `src/lib/` contains validation and statistics; `src/components/` contains reusable native UI and charts; `src/theme.ts` contains colours and typography. The letterhead and notes are reference material, not instructions to execute.
